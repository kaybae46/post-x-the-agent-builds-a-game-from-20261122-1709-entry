A short vertical video about an AI coding agent building a tiny browser game from one prompt while you watch. The video shows the one prompt, the agent working, and the finished game — **Neon Catch**, a neon canvas game where a glowing paddle catches falling stars (+1 point per catch, 3 lives, game-over screen with restart) — actually running, and ends on the game running with the call to come build on make.fun, followed by make.fun's referral end card.

The game itself is `game.html` in this repo: open it in a browser, press START, and play with arrow keys, mouse, or touch. The video (`video.mp4`, 33.5 s, 1080x1920) is handed to the poster for upload to X and is not committed here; `POST.json` names the X post once it is live, and `POST_TEXT.md` holds the exact post text.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
